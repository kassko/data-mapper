# PR #10: Upgrade to PHP 8.1 minimum and remove compatibility workarounds

**Author:** Copilot  
**Created:** 2025-12-19  
**Merged:** 2025-12-19  

---

Bumps minimum PHP requirement from 8.0 to 8.1, removing obsolete compatibility code.

## Changes

- **Requirements**: PHP >=8.1 in `composer.json`, CI matrix now tests 8.1-8.4
- **Reflection**: Removed 14 `setAccessible(true)` calls from tests (unnecessary in PHP 8.1+)
- **Array checking**: Simplified `isListArray()` to use native `array_is_list()` directly

```php
// Before (PHP 8.0 compatible)
private function isListArray(array $array): bool
{
    if (empty($array)) return true;
    if (function_exists('array_is_list')) {
        return array_is_list($array);
    }
    // Manual fallback for PHP 8.0...
}

// After (PHP 8.1+)
private function isListArray(array $array): bool
{
    return array_is_list($array);
}
```

**Net**: -31 lines across 10 files. All 105 tests passing.
