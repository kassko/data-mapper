# PR: Integration Tests for PHP 8 Attributes - PropertyInstantiatingHook, SinglePropDataSource, DataSource

**Date:** 2026-01-03
**Branch:** `feat/tests/CoverPhpAttributes`

## Summary

This PR adds comprehensive integration tests for three PHP 8 attributes that were lacking proper test coverage:

1. **PropertyInstantiatingHook** - Hook executed after object instantiation
2. **SinglePropDataSource** - Single property data source for lazy loading
3. **DataSource** - Alias of SinglePropDataSource

Additionally, this PR includes new documentation for the test suite.

## Usage Examples

### Running New Tests

```bash
# All new attribute tests
./vendor/bin/phpunit tests/Integration/Attributes/PropertyInstantiatingHook \
                     tests/Integration/Attributes/SinglePropDataSource \
                     tests/Integration/Attributes/DataSource

# With TestDox output
./vendor/bin/phpunit tests/Integration/Attributes/DataSource --testdox
```

### PropertyInstantiatingHook Example

```php
#[PropertyInstantiatingHook(after_instantiating: 'onInstantiated', args: ['##object'])]
class TrackedEntity
{
    private bool $instantiationTracked = false;
    
    public function onInstantiated(self $entity): void
    {
        $this->instantiationTracked = true;
    }
}
```

### SinglePropDataSource/DataSource Example

```php
class Product
{
    use LoadableTrait;
    
    #[SinglePropDataSource(class: ProductDataSource::class, method: 'getName', args: ['#id'])]
    private ?string $name = null;
    
    public function getName(): ?string
    {
        $this->loadProperty('name');
        return $this->name;
    }
}
```
