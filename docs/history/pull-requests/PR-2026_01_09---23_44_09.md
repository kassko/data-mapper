# feat: Add ObjectMapper for DTO Source Mapping

## Summary

This PR introduces the `ObjectMapper` class and related infrastructure for mapping domain objects from DTO (Data Transfer Object) sources. While the existing `Hydrator` works with raw data arrays, the new `ObjectMapper` works with source objects, enabling seamless DTO-to-domain transformations.

## Features

### ObjectMapper Class

A new public API class (`src/ObjectMapper.php`) that provides a clean interface for mapping domain objects from DTO sources:

```php
$objectMapper = $dataMapper->getObjectMapper();

// Map a DTO to a new domain object
$person = $objectMapper->map(Person::class, $personDto);

// Map to an existing object
$objectMapper->mapToExisting($existingPerson, $personDto);
```

### Deep Path Mapping

Support for nested property paths (e.g., `address.street.number`) allowing properties to be mapped from deeply nested DTO structures:

```php
class Person
{
    #[Property(sourceField: 'address.street')]
    private ?string $street = null;
    
    #[Property(sourceField: 'address.city')]
    private ?string $city = null;
}
```

### CustomObjectMapper Attribute

A new attribute for defining custom property-level object mappers:

```php
#[CustomObjectMapper(
    key: 'money_mapper',
    inputClass: MoneyDto::class,
    outputClass: Money::class,
    nullableInput: true,
    nullableOutput: false
)]
private Money $total;
```

### DataMapper/DataMapperBuilder Enhancements

- `DataMapper::getObjectMapper()` - Get the ObjectMapper instance
- `DataMapper::getCustomObjectMapper(string $key)` - Retrieve a custom object mapper
- `DataMapper::getCustomHydrator(string $key)` - Retrieve a custom hydrator
- `DataMapperBuilder::addCustomObjectMapper(string $key, callable $callable)` - Register custom object mappers

## Usage Example

```php
// Build DataMapper with custom object mapper
$builder = new DataMapperBuilder();
$builder->addCustomObjectMapper('address_mapper', function(object $source): Address {
    return new Address(
        street: $source->street,
        city: $source->city
    );
});
$dataMapper = $builder->build();

// Map DTOs to domain objects
$objectMapper = $dataMapper->getObjectMapper();
$person = $objectMapper->map(Person::class, $personDto);
```
