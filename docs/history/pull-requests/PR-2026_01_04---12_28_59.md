# PR: Enablable Attributes & Handle Pattern Refactoring

**Branch:** `feat_break/code/EnablableAttributes_DesignImprov_More`
**Date:** January 4, 2026

## Summary

This PR introduces a comprehensive refactoring of the attribute system with three major improvements:

1. **`enabled` Field on All Attributes**: All attributes now support an `enabled: bool` parameter to dynamically activate/deactivate them
2. **Handle Pattern Refactoring**: Replaced `KeepProperty/SkipProperty/KeepAllProperties/SkipAllProperties` with unified `HandleProperty/HandleAllProperties` pattern
3. **RejectAttributeCascading**: New attribute to control cascading inheritance from parent classes

## Breaking Changes ⚠️

### 1. Attribute Pattern Refactoring

**Before:**
```php
#[SkipAllProperties]
class Entity {
    #[KeepProperty]
    private string $name;
    
    #[SkipProperty(when: "expr(...)")]
    private string $email;
}
```

**After:**
```php
#[HandleAllProperties(value: false)]
class Entity {
    #[HandleProperty(value: true)]
    private string $name;
    
    #[HandleProperty(value: false, when: "expr(...)")]
    private string $email;
}
```

### 2. Property Attribute Field Rename

**Before:**
```php
#[Property(key: 'name', keepWhen: "expr(...)")]
```

**After:**
```php
#[Property(key: 'name', handleWhen: "expr(...)")]
```

### 3. DataSourcesStore/PropertyConfigStore Parameter Rename

**Before:**
```php
#[DataSourcesStore([new DataSource(...)])]
#[PropertyConfigStore(configs: [new PropertyConfig(...)])]
```

**After:**
```php
#[DataSourcesStore(items: [new DataSource(...)])]
#[PropertyConfigStore(items: [new PropertyConfig(...)])]
```

## New Features

### 1. `enabled` Field on All Attributes

All attributes now support an `enabled: bool = true` parameter:

```php
#[DataSourcesStore(items: [
    new DataSource(id: 'active', class: ActiveService::class),
    new DataSource(id: 'disabled', class: DisabledService::class, enabled: false),
], enabled: true)]
```

Disabled attributes are completely ignored during processing.

### 2. HandleProperty/HandleAllProperties

Unified pattern for property inclusion/exclusion:

| Attribute | Parameters | Description |
|-----------|------------|-------------|
| `HandleAllProperties(value: bool)` | `value`, `cascade`, `enabled` | Class-level default behavior |
| `HandleProperty(value: bool, when: ?string)` | `value`, `when`, `cascade`, `enabled` | Property-level control |

**Logic for `when` expression:**
- `value=true + when=true` → Hydrate
- `value=true + when=false` → Skip (SAUF/EXCEPT)
- `value=false + when=true` → Skip
- `value=false + when=false` → Hydrate (SAUF/EXCEPT)

### 3. RejectAttributeCascading

Prevents inheriting attributes from parent classes:

```php
#[RejectAttributeCascading]
#[DataSourcesStore(items: [...])]
class ChildEntity extends ParentEntity {
    // Does NOT inherit ParentEntity's DataSourcesStore
}
```

### 4. handleWhen on DataSourceRef

DataSourceRef now supports conditional handling:

```php
#[DataSourceRef(id: 'source', handleWhen: "expr(contextKeyExists('load_data'))")]
```

SkipProperty → HandleProperty(value: false)
