# PR: Constructor Optional Parameters and Indexed Adder Support

## Summary

This PR introduces two major improvements to DataMapper's parameter handling:

1. **Relaxed Constructor Parameter Constraints**: Constructor parameters can now be optional without requiring `#[Param]` attribute
2. **Indexed Adder Support**: New `TYPE_INDEXED_ADDER` setter type for associative array properties with `#[Param]` support

## Changes

### 1. Optional Constructor Parameters

**Before**: All constructor parameters were required to have a `#[Param]` attribute.

**After**: Constructor parameters must **either be optional OR have a `#[Param]` attribute**. Optional parameters without `#[Param]` use their default value.

```php
// Before: Would throw exception
class Person
{
    public function __construct(?string $ssn = null) {} // Error!
}

// After: Works correctly
class Person
{
    public function __construct(
        ?string $ssn = null,  // Optional - uses default value
        #[Param(value: "expr(context('userId'))")]
        string $id = ''  // Resolved from context
    ) {}
}
```

### 2. Indexed Adder (`TYPE_INDEXED_ADDER`)

New setter type that passes both the key and value from associative arrays:

```php
#[Setter(name: 'addAddress', type: Setter::TYPE_INDEXED_ADDER)]
private array $addresses = [];

public function addAddress(mixed $key, mixed $value): void {
    $this->addresses[$key] = $value;
}

// With data: ['addresses' => ['home' => '123 Main St', 'work' => '456 Office']]
// Calls: addAddress('home', '123 Main St'), addAddress('work', '456 Office')
```

### 3. Param Support in Indexed Adder

The first two parameters (index and value) must NOT have `#[Param]`. Additional parameters (from 3rd position) can have `#[Param]`:

```php
public function addAddress(
    mixed $index,    // NO Param - receives array key
    mixed $address,  // NO Param - receives array value
    #[Param(value: "expr(context('address_prefix'))")]
    string $prefix = ''  // Resolved from context
): void {
    $this->addresses[$prefix . $index] = $address;
}
```

## Breaking Changes

- Constructor parameters without `#[Param]` that are NOT optional will now throw an error with updated message: "must either be optional or have a #[Param] attribute"

## Migration Guide

### Constructor Parameters

If you have constructor parameters without `#[Param]`:

1. **Make them optional**: Add a default value
   ```php
   public function __construct(string $name = '') {}
   ```

2. **Or add `#[Param]`**: If the value should be resolved
   ```php
   public function __construct(
       #[Param(value: "expr(context('name'))")]
       string $name
   ) {}
   ```

### Using Indexed Adder

For associative array properties, use the new `TYPE_INDEXED_ADDER`:

```php
#[Setter(name: 'addItem', type: Setter::TYPE_INDEXED_ADDER)]
private array $items = [];

public function addItem(mixed $key, mixed $value): void {
    $this->items[$key] = $value;
}
```
