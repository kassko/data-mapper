# PR #9: Implement 6 evolutions: KeepProperty, Getter/Setter, Context, Expression enrichment, and PHP 8.0 fixes

**Author:** Kassko 
**Created:** 2025-12-19  
**Merged:** 2025-12-19  

---

Adds six new features to the data-mapper library with PHP 8.0+ compatibility.

## Changes

### 1. KeepProperty Attribute
- Alias for `Property` when used solely for inclusion marking
- Works with `SkipAllProperties` to selectively include properties

```php
#[SkipAllProperties]
class User {
    #[KeepProperty]  // Included
    private string $name;
    
    private string $internal;  // Excluded
}
```

### 2. Rename supplySeveralProps → supplySeveralProperties
- Updated `DataSource` attribute parameter name
- Changed references in `LazyLoader` and all fixture files

### 3. Getter/Setter Attributes with Resolution
- `#[Setter(name: 'methodName', type: 'setter|adder')]`
- `#[Getter(name: 'methodName', type: 'getter|isser|haser')]`
- Write resolution order: explicit setter → adder for lists → conventional setter → reflection
- Adder pattern: `addEmailsItem()` called per item for list arrays

```php
class Person {
    #[Setter(name: 'setName')]
    private string $firstName;
    
    private array $emails;  // Uses addEmailsItem() for ['a', 'b']
}
```

### 4. Context Attribute and Registry
- `#[Context(['key' => 'value'])]` sets context when property loads
- Static `ContextRegistry` for get/set/has/clear operations
- Last write wins for duplicate keys

### 5. Expression Language Enhancement
- `service('id')` - resolves from service container
- `env_var('KEY')` - gets environment variable (preserves empty strings)
- `context('key')` - retrieves from ContextRegistry

```php
#[DataSource(
    class: CarRepository::class,
    method: 'find',
    args: ["expr(context('current_shop_id'))"]
)]
```

### 6. PHP 8.0 Compatibility
- Fixed `phpunit.xml.dist` - removed PHP 8.1+ attributes (`cacheDirectory`, `<cache>`)
- Made `DataSource` repeatable on classes via `Attribute::IS_REPEATABLE`
- Replaced `DataSourcesStore([new DataSource(...)])` with multiple `#[DataSource(...)]` (PHP 8.0 forbids `new` in attributes)
- Enhanced `AttributeReader` to read from both DataSourcesStore and repeatable attributes
- Fixed `ServiceResolver` to handle pre-instantiated objects from locators

All 105 tests passing with PHP 8.0+ compatibility maintained.
