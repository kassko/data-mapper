# PR-2025_12_28_12_37_26: Major Refactoring - LoadableTrait, Param Attribute, and Hydrating Hooks

## Summary

This PR implements several major improvements to the DataMapper library:

1. **LoadableTrait::isPropertyLocked() visibility change** - Changed from `public` to `protected` for better encapsulation
2. **LoadableInternalTrait removal** - Deleted unused trait and migrated all uses to LoadableTrait
3. **New Param attribute** - Added support for constructor/getter/setter parameter injection
4. **PropertyHydratingHook improvements** - Fixed hook execution and added comprehensive tests
5. **Documentation restructuring** - Reorganized docs/architecture with FR/EN structure

## Breaking Changes

This is an alpha version - no backward compatibility is maintained.

### 1. LoadableTrait::isPropertyLocked() is now protected

**Before:**
```php
$object->isPropertyLocked('propertyName'); // Direct call
```

**After:**
```php
// Access via Loader using reflection
$loader = LoaderRegistry::get();
// Loader internally uses checkPropertyLockedViaReflection()
```

### 2. LoadableInternalTrait removed

All usages must be replaced with `LoadableTrait`.

## New Features

### Param Attribute

The new `#[Param]` attribute enables parameter injection for:

#### Constructor parameters
All constructor parameters MUST have Param attribute. Property references are forbidden.

```php
class Person
{
    public function __construct(
        #[Param(value: "expr(context('userId'))")]
        string $id
    ) {
        $this->id = $id;
    }
}
```

#### Getter parameters
Parameters with Param are injected automatically.

```php
public function getName(
    #[Param(value: "expr(service('formatter'))")]
    $formatter = null
): ?string {
    $this->loadProperty('name');
    return $formatter?->format($this->name);
}
```

#### Setter parameters
First parameter MUST NOT have Param; additional parameters MUST have Param.

```php
public function setEmail(
    $email,  // Value from hydration
    #[Param(value: "expr(context('domain'))")]
    $domain = ''
): void {
    $this->email = $email . '@' . $domain;
}
```

### Supported Param values

- Static: `"fixed value"`
- Context: `"expr(context('key'))"`
- Service: `"expr(service('serviceId'))"`
- Source: `"expr(source('sourceId'))"`
- Property (getters/setters only): `"#propertyName"` or `"expr(property('name'))"`
- Object (getters/setters only): `"##object"`
