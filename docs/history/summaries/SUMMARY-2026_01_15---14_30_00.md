# Summary: Naming Convention Auto-Detection Fix

**Date**: 2026-01-15  
**Branch**: `fix/code/mapping`

## Overview

Fixed a bug in recursive hydration where nested objects failed to hydrate when raw data keys used a different naming convention than PHP properties.

## Changes Made

### 1. PropertyMappingRegistry (New Class)

**File**: `src/Registry/PropertyMappingRegistry.php`

A static registry using `WeakMap` for bidirectional property-to-sourceField mapping:

```php
// Register a mapping
PropertyMappingRegistry::register($object, 'firstName', 'first_name');

// Lookup in both directions
PropertyMappingRegistry::getSourceField($object, 'firstName');  // Returns 'first_name'
PropertyMappingRegistry::getPropertyName($object, 'first_name'); // Returns 'firstName'
```

### 2. Naming Convention Utilities

**File**: `src/Loader/Loader.php`

Added utility methods:
- `camelToSnake(string $input): string` - Converts `firstName` → `first_name`
- `snakeToCamel(string $input): string` - Converts `first_name` → `firstName`
- `findMatchingFieldInData(ReflectionProperty $property, array $data): ?string` - Finds matching key with convention detection
- `getSourceFieldNameWithData(ReflectionProperty $property, object $object, array $data): string` - Gets source field with auto-detection

### 3. Updated Hydration Methods

Modified to use `getSourceFieldNameWithData()` instead of `getSourceFieldNameAndRegister()`:
- `hydrateProperty()` (line ~1667)
- `hydrateObject()` (line ~2046)
- `hydrateFromDto()` (line ~2811)

## Priority Rules

1. **Explicit `sourceField`**: Always used if defined via `#[Property(sourceField: 'xxx')]`
2. **Exact match**: Property name found directly in raw data
3. **Snake case**: Try converting `firstName` → `first_name`
4. **Camel case**: Try converting `first_name` → `firstName`

## Example

```php
// Before fix: This would FAIL for nested objects
$rawData = [
    'company_name' => 'ACME',
    'employees' => [
        ['first_name' => 'John', 'last_name' => 'Doe'],
    ],
];

class Company {
    public string $companyName;  // first_name ❌ not found
    #[Property(class: Employee::class)]
    public array $employees;     // Nested hydration FAILED
}

// After fix: Works automatically!
$company = $hydrator->hydrate(Company::class, $rawData);
// $company->companyName === 'ACME' ✓
// $company->employees[0]->firstName === 'John' ✓
```

## Backward Compatibility

✅ Fully backward compatible. Existing code with explicit `sourceField` mappings works unchanged.
