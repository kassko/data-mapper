## Overview

Implemented comprehensive DTO (Data Transfer Object) handling support for the data-mapper library. This feature enables mapping domain objects from DTO sources in addition to the existing raw data array hydration.

---

## Implementation Details

### 1. ObjectMapper Class (`src/ObjectMapper.php`)

A new public API class providing a clean interface for mapping domain objects from DTO sources:

**Methods:**
- `map(string $className, object $sourceObject): object` - Creates and maps a new object
- `mapToExisting(object $object, object $sourceObject): object` - Maps to an existing object

**Features:**
- Wraps internal Loader functionality
- Supports `#[Param]` attribute for instantiation
- Executes `#[PropertyInstantiatingHook]` hooks
- Handles deep path resolution

### 2. CustomObjectMapper Attribute (`src/Attribute/CustomObjectMapper.php`)

A new attribute for custom property-level object mappers:

**Parameters:**
| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `key` | string | (required) | Mapper identifier |
| `inputClass` | string\|null | null | Expected input type |
| `outputClass` | string\|null | null | Expected output class |
| `nullableInput` | bool | true | Allow null input |
| `nullableOutput` | bool | true | Allow null output |
| `cascade` | bool | true | Cascades to child classes |
| `enabled` | bool | true | Attribute is active |

### 3. DataMapper Enhancements (`src/DataMapper.php`)

**New Properties:**
- `private array $customHydrators`
- `private array $customObjectMappers`
- `private ?ObjectMapper $objectMapper`

**New Methods:**
- `getObjectMapper(): ObjectMapper` - Returns cached ObjectMapper instance
- `getCustomHydrator(string $key): ?callable` - Retrieves custom hydrator by key
- `getCustomObjectMapper(string $key): ?callable` - Retrieves custom object mapper by key

**Constructor Updated:**
- Added `array $customObjectMappers = []` parameter

### 4. DataMapperBuilder Enhancements (`src/DataMapperBuilder.php`)

**New Properties:**
- `private array $customObjectMappers = []`

**New Methods:**
- `addCustomObjectMapper(string $key, callable $callable): self`
- `getCustomObjectMappers(): array`

### 5. Loader Enhancements (`src/Loader/Loader.php`)

**New Public Methods:**
- `convertSourceToData(mixed $source): array` - Converts object/array to data array
- `getCustomHydrators(): array` - Returns all custom hydrators
- `getCustomHydrator(string $key): ?callable` - Returns specific custom hydrator

**New Private Methods:**
- `extractObjectData(object $source): array` - Extracts properties via reflection
- `getPropertyValueFromObject(object, string, ?ReflectionClass): mixed` - Gets value via getters/reflection
- `propertyExists(object, string): bool` - Checks if property exists
- `mapObjectFromSource(object, object, array, ?Property, int): void` - Maps from source object
- `resolveValueFromSource(string $fieldPath, array $data, ?object): mixed` - Resolves value with deep path support
- `resolveDeepPath(string $path, array $data, ?object): mixed` - Handles "a.b.c" paths
- `sourceFieldExists(string $fieldPath, array $data, ?object): bool` - Checks field existence

## Usage Examples

### Basic DTO Mapping
```php
$objectMapper = $dataMapper->getObjectMapper();
$person = $objectMapper->map(Person::class, $personDto);
```

### Deep Path Mapping
```php
class Person
{
    #[Property(sourceField: 'address.street')]
    private ?string $street = null;
}
```

### Custom Object Mappers
```php
$builder->addCustomObjectMapper('money_mapper', fn($dto) => new Money($dto->amount, $dto->currency));

$mapper = $dataMapper->getCustomObjectMapper('money_mapper');
```

## Hydrator vs ObjectMapper Comparison

| Feature | Hydrator | ObjectMapper |
|---------|----------|--------------|
| Input | Array (raw data) | Object (DTO) |
| Method | `hydrate()` | `map()` |
| Use case | API responses, JSON | DTO transformations |
| Deep paths | Nested arrays | Object traversal |
