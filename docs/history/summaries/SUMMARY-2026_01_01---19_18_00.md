Summary of changes
The bug was that the Loader was not resolving the methodAlias ​​property of the SinglePropDataSource, MultiPropDataSource, and DataSource attributes.

Corrections made in src/Loader/Loader.php:
Added imports for MethodAlias ​​and MethodAliasNotFoundException

Added the resolveMethodAlias() method which:

Uses AttributeReader::getMethodAliasMap() to retrieve aliases from the class hierarchy
Throws MethodAliasNotFoundException if the alias does not exist
Respects the cascading property of aliases
Modified callDataSource() to:

Check if methodAlias ​​is defined on the source
Resolve the alias to class and method
Support ##object to reference the current object
Modified executeDataSource() with the same logic

Tests created in tests/Integration/Attributes/MethodAliasTest.php:
testMethodAliasWithSinglePropDataSource - Test with SinglePropDataSource
testMethodAliasWithMultiPropDataSource - Test with MultiPropDataSource
testMethodAliasWithObjectReference - Test with ##object
testMethodAliasCascading - Test for alias inheritance
testMethodAliasNoCascade - Test that cascade: false prevents inheritance
testMultipleMethodAliases - Test for multiple aliases on a class
