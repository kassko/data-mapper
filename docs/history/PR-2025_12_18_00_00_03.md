# PR #5: Add DataSourcesStore, DataSourceRef, Field attributes and expression language

**Author:** Kassko 
**Created:** 2025-12-18  
**Merged:** 2025-12-18  

---

Adds centralized DataSource configuration with id-based referencing, field name mapping, batch property hydration, and expression language for dependency chains.

## New Attributes

**DataSourcesStore** - Class-level attribute grouping DataSources with unique ids:
```php
#[DataSourcesStore([
    new DataSource(id: 'personSource', class: PersonDataSource::class, 
                   method: 'getData', args: ['#id'], supplySeveralFields: true),
    new DataSource(id: 'carSource', class: CarRepository::class, 
                   method: 'find', args: ["expr(source('personSource')['car_id'])"])
])]
class Person { /* ... */ }
```

**DataSourceRef** - References DataSource by id instead of repeating configuration:
```php
#[DataSourceRef(id: 'personSource')]
private ?string $name = null;
```

**Field** - Maps property names to different data keys:
```php
#[DataSourceRef(id: 'personSource')]
#[Field(name: 'first_name')]
private ?string $firstName = null;  // Reads from 'first_name' key
```

## Batch Hydration

**supplySeveralFields** option on DataSource:
- `false` (default): Returns value directly, or array with property names as keys for same-signature properties
- `true`: Single call hydrates all properties with matching DataSourceRef in one execution

```php
// Single call to personSource hydrates firstName, name, and email
new DataSource(id: 'personSource', /* ... */, supplySeveralFields: true)
```

## Expression Language

**Property references**: `#id` resolves to `$this->id`

**Source expressions**: `expr(source('personSource')['car_id'])` executes DataSource and extracts array key

**Dependency resolution**: Loading `car` automatically loads `personSource` first, caches result

## Implementation

- `src/Expression/` - ExpressionParser and SourceFunctionProvider for evaluation and caching
- `src/Metadata/AttributeReader` - Extended with methods for new attributes and DataSource map building
- `src/LazyLoader/LazyLoader` - Refactored to handle store resolution, batch hydration, expression evaluation
- Source ids validated with `[a-zA-Z0-9_-]+` regex, error messages sanitized

## Testing
