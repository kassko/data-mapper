# PR-2025_12_30_00_55_08: Hydrator API Exposure and README Improvements

## Summary

This PR exposes the hydration functionality to end users via a clean `Hydrator` API and fixes several issues in the README.md Quick Start section.

## Changes

### 1. Hydrator API Exposure

The library now provides a dedicated `Hydrator` class for hydrating objects from raw data:

```php
$hydrator = $dataMapper->getHydrator();

$rawData = ['first_name' => 'John', 'last_name' => 'Doe'];
$person = $hydrator->hydrate(Person::class, $rawData);
```

**New Hydrator class features:**
- `hydrate(string $className, array $rawData): object` - Instantiates and hydrates a new object
- `hydrateExisting(object $object, array $rawData): object` - Hydrates an existing object instance

The Hydrator:
- Supports constructor parameter injection via `#[Param]` attributes
- Executes `PropertyInstantiatingHook` callbacks after object creation
- Executes `PropertyHydratingHook` callbacks before/after hydration
- Executes `PropertySettingHook` callbacks when setting properties
- Respects `#[Property]` attribute mappings for field names
- Handles nested object hydration

### 2. Custom Hydrators Fix

Fixed an issue where custom hydrators registered via `DataMapperBuilder::addCustomHydrator()` were not being passed to the `Loader`. Custom hydrators now work correctly.

### 3. README.md Improvements

Fixed several issues in the Quick Start section:

**Syntax error fix:**
```php
// Before (invalid syntax)
#[DataSource(class: '...', method: '...', args['#id'])]

// After (correct syntax)

```

**Improved section titles and formulations:**
- "Hydrate properties" → "Hydrate properties from raw data"
- Added missing semicolons in code examples
- Clarified service provider section

## API Usage Examples

### Basic Hydration

```php
use Kassko\DataMapper\DataMapperBuilder;

$builder = new DataMapperBuilder();
$dataMapper = $builder->build();

$hydrator = $dataMapper->getHydrator();

// Create and hydrate a new object
$person = $hydrator->hydrate(Person::class, [
    'first_name' => 'John',
    'last_name' => 'Doe',
    'email' => 'john@example.com'
]);
```

### Hydrate Existing Object

```php
$person = new Person();
$person->setId(123);

$hydrator->hydrateExisting($person, [
    'first_name' => 'John',
    'email' => 'john@example.com'
]);
```

### With Custom Hydrators

```php
$builder = new DataMapperBuilder();
$builder->addCustomHydrator('json_parser', function(array $data): ?object {
    return new JsonContent($data);
});
$dataMapper = $builder->build();

$hydrator = $dataMapper->getHydrator();
// Custom hydrators are now available during hydration
```
