### Task 2: Hydrator API Exposure ✅
Created a new `Hydrator` class that provides a clean API for hydrating objects from raw data:

```php
$hydrator = $dataMapper->getHydrator();

$rawData = ['first_name' => 'John', 'last_name' => 'Doe'];
$person = $hydrator->hydrate(Person::class, $rawData);
```

**Implementation details:**
- Created `src/Hydrator.php` with two main methods:
  - `hydrate(string $className, array $rawData): object` - Creates and hydrates a new object
  - `hydrateExisting(object $object, array $rawData): object` - Hydrates an existing object
- Added `getHydrator()` method to `DataMapper` class
- Fixed custom hydrators not being passed from `DataMapperBuilder` to `DataMapper` to `Loader`
- Updated `DataMapper` constructor to accept and pass custom hydrators
