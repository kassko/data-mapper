## Key Implementation Details

### Cascading Logic in AttributeReader

1. **Class hierarchy traversal**: `getClassHierarchy()` builds the full chain from current class to root
2. **Trait recursion**: `collectDataSourcesFromTraits()` and `collectPropertyConfigsFromTraits()` recursively collect from nested traits
3. **Merge order**: Process from oldest ancestor to current class, so child definitions override parent/trait
4. **Conflict detection**: When same ID exists, log warning and let child win

### Loader Integration

1. Constructor accepts optional `AttributeCascadeCollector`
2. Creates default collector with logger if none provided
3. Passes collector to `AttributeReader`
4. Uses `readCascadedPropertyConfigStore()` for polymorphic hydration

### Event Types Collected

| Event | Severity | When |
|-------|----------|------|
| `TYPE_DATASOURCES_STORE_MERGE` | INFO | DataSourcesStore merged from parent/trait |
| `TYPE_PROPERTY_CONFIG_STORE_MERGE` | INFO | PropertyConfigStore merged from parent/trait |
| `TYPE_DATASOURCE_ID_CONFLICT` | WARNING | DataSource ID in child overrides parent/trait |
| `TYPE_PROPERTY_CONFIG_ID_CONFLICT` | WARNING | PropertyConfig ID in child overrides parent/trait |
| `TYPE_PROPERTY_ATTRIBUTE_OVERRIDE` | WARNING | Child property shadows parent property with attributes |

## Usage Example

```php
// Parent class defines data sources
#[DataSourcesStore([
    new SinglePropDataSource(id: 'parentSource', class: ParentDataSource::class, method: 'getData'),
])]
abstract class BaseEntity {}

// Trait defines additional data sources
#[DataSourcesStore([
    new SinglePropDataSource(id: 'traitSource', class: TraitDataSource::class, method: 'getData'),
])]
trait DataSourceTrait {}

// Child inherits both and can reference them
class ChildEntity extends BaseEntity
{
    use DataSourceTrait;
    
    #[DataSourceRef(id: 'parentSource')] // Works!
    private ?string $fromParent = null;
    
    #[DataSourceRef(id: 'traitSource')] // Works!
    private ?string $fromTrait = null;
}
```
