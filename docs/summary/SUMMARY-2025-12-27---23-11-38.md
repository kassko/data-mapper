# Summary of Changes - 2025-12-27

## Objectives

Two major refactorings of the attribute system:

1. **Improved `DataSourceRef` design**: rename `discriminator` to `rule`, add `defaultCandidate`
2. **PropertyCandidates pattern refactoring**: create `PropertyConfig`/`PropertyConfigStore`, modify `Property`, remove old attributes

No backward compatibility (alpha version).

---

## 1. DataSourceRef - Design Improvement

### Modified file
- `src/Attribute/DataSourceRef.php`

### Changes
- Renamed `discriminator` → `rule` in candidates
- Added the `defaultCandidate` parameter (required with `candidates`)
- New validation: `candidates` and `defaultCandidate` must be present together or absent together
- `fallbacks` and `exceptionOnNoValidDataSource` can no longer be used with `candidates`

### Before
```php
#[DataSourceRef(candidates: [
    ['id' => 'sourceA', 'discriminator' => "expr(context('flag'))"],
    ['id' => 'sourceB', 'discriminator' => 'expr(true)'],
])]
```

### After
```php
#[DataSourceRef(
    candidates: [
        ['id' => 'sourceA', 'rule' => "expr(context('flag'))"],
    ],
    defaultCandidate: ['id' => 'sourceB']
)]
```

## 2. New PropertyConfig Pattern

### New files created
| File | Description |
|------|-------------|
| `src/Attribute/PropertyConfig.php` | Reusable configuration with unique ID |
| `src/Attribute/PropertyConfigStore.php` | Class-level store containing PropertyConfig items |
| `docs/attributes/PropertyConfig.md` | Documentation |
| `docs/attributes/PropertyConfigStore.md` | Documentation |

### Modified file
- `src/Attribute/Property.php`

### New parameters on Property
| Parameter | Type | Description |
|-----------|------|-------------|
| `config` | `?string` | Reference to a PropertyConfig by ID |
| `configCandidates` | `?array` | Array of `['id' => string, 'rule' => string]` |
| `defaultConfigCandidate` | `?string` | Default config ID if no rule matches |

### Before
```php
#[PropertyCandidates([
    new PropertyCandidate(
        discriminator: "expr(rawDataItemExists('gasolineKind'))",
        property: new Property(class: GasolineCar::class)
    ),
    new PropertyCandidate(
        discriminator: "expr(rawDataItemExists('energyProvider'))",
        property: new Property(class: ElectricCar::class)
    )
])]
private array $cars = [];
```

### After
```php
#[PropertyConfigStore([
    new PropertyConfig(id: 'gasolineCar', class: GasolineCar::class),
    new PropertyConfig(id: 'electricCar', class: ElectricCar::class),
])]
class Garage
{
    #[Property(
        configCandidates: [
            ['id' => 'gasolineCar', 'rule' => "expr(rawDataItemExists('gasolineKind'))"],
            ['id' => 'electricCar', 'rule' => "expr(rawDataItemExists('energyProvider'))"],
        ],
        defaultConfigCandidate: 'gasolineCar'
    )]
    private array $cars = [];
}
```

  - `mergePropertyConfig()`: merges a PropertyConfig into a Property

- Updated imports
