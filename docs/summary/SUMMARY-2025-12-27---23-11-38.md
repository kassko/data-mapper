# Résumé des modifications - 2025-12-27

## Objectifs

Deux refactorings majeurs du système d'attributs :

1. **Amélioration du design de `DataSourceRef`** : renommer `discriminator` en `rule`, ajouter `defaultCandidate`
2. **Refactoring du pattern PropertyCandidates** : créer `PropertyConfig`/`PropertyConfigStore`, modifier `Property`, supprimer les anciens attributs

Aucune rétrocompatibilité (version alpha).

---

## 1. DataSourceRef - Amélioration du design

### Fichier modifié
- `src/Attribute/DataSourceRef.php`

### Changements
- Renommé `discriminator` → `rule` dans les candidates
- Ajouté le paramètre `defaultCandidate` (obligatoire avec `candidates`)
- Nouvelle validation : `candidates` et `defaultCandidate` doivent être présents ensemble ou absents ensemble
- `fallbacks` et `exceptionOnNoValidDataSource` ne peuvent plus être utilisés avec `candidates`

### Avant
```php
#[DataSourceRef(candidates: [
    ['id' => 'sourceA', 'discriminator' => "expr(context('flag'))"],
    ['id' => 'sourceB', 'discriminator' => 'expr(true)'],
])]
```

### Après
```php
#[DataSourceRef(
    candidates: [
        ['id' => 'sourceA', 'rule' => "expr(context('flag'))"],
    ],
    defaultCandidate: ['id' => 'sourceB']
)]
```

## 2. Nouveau pattern PropertyConfig

### Nouveaux fichiers créés
| Fichier | Description |
|---------|-------------|
| `src/Attribute/PropertyConfig.php` | Configuration réutilisable avec ID unique |
| `src/Attribute/PropertyConfigStore.php` | Store au niveau classe contenant les PropertyConfig |
| `docs/attributes/PropertyConfig.md` | Documentation |
| `docs/attributes/PropertyConfigStore.md` | Documentation |

### Fichier modifié
- `src/Attribute/Property.php`

### Nouveaux paramètres sur Property
| Paramètre | Type | Description |
|-----------|------|-------------|
| `config` | `?string` | Référence vers un PropertyConfig par ID |
| `configCandidates` | `?array` | Array de `['id' => string, 'rule' => string]` |
| `defaultConfigCandidate` | `?string` | ID du config par défaut si aucune rule ne match |

### Avant
```php
#[PropertyCandidates([
    new PropertyCandidate(
        discriminator: "expr(rawDataItemExists('gasolineKind'))",
        property: new Property(class: GasolineCar::class)
    ),
    new PropertyCandidate(
        discriminator: "expr(rawDataItemExists('energyProvider'))",
        property: new Property(class: ElectricCar::class)
    )
])]
private array $cars = [];
```

### Après
```php
#[PropertyConfigStore([
    new PropertyConfig(id: 'gasolineCar', class: GasolineCar::class),
    new PropertyConfig(id: 'electricCar', class: ElectricCar::class),
])]
class Garage
{
    #[Property(
        configCandidates: [
            ['id' => 'gasolineCar', 'rule' => "expr(rawDataItemExists('gasolineKind'))"],
            ['id' => 'electricCar', 'rule' => "expr(rawDataItemExists('energyProvider'))"],
        ],
        defaultConfigCandidate: 'gasolineCar'
    )]
    private array $cars = [];
}
```
